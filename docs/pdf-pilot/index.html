NIME 2021–2022 archive PDF regeneration pilot

Regenerating PubPub papers in the NIME template

Fourteen papers of different complexity, rebuilt automatically from the PubPub export with scripts/make_pdf.py (pandoc + nimeart.cls) and checked by scripts/qa_pdf.py. No hand editing. The method, every revision and the open issues are in the conversion log; discussion on nime-website#94.

QA summary (revision 4)

All 14 compile with zero LaTeX errors and no undefined citations; every figure in the HTML is present. "Small text" is words set below 0.6× body size and also counts text inside vector figures, so treat it as a hint. "Sparse pages" are code appendices and one table longer than a column. Full numbers: qa_report.md.
